# Changelog for release 0.0.8

This release makes the following changes:

- Added handling of deep-links
    - Links of the form `/l/*` are treated as deep-links. The path is matched against configured links and depending on
      the device, the user is forwarded to the appropriate destination
    - Deep-links currently exist for the following destinations
        - Invitation status updates
        - Email-verification

- Email-verification screen behaviour fixed
    - Removed "customization" of having the email address displayed
